| 2026-10-11 | Shared code stays in the template for now; extract to a package later. | Clients are full copies; a package needs a private registry + deploy changes. | 2026-10-11 | Feature flags = `SiteSetting` keys, all default OFF, plus env kill switches. | 2026-10-11 | Encrypt third-party tokens with the existing AES-256-GCM scheme, new key derivation label per domain (`pos-creds:`, `delivery-creds:`). | 2026-10-11 | Test runner: **Vitest** (dev dependency), contract tests with a mocked `fetch` and JSON fixtures. | Fast, TS-native, no Babel; mocking global fetch keeps adapters dependency-free. | Jest (heavier config with ESM/TS). |
